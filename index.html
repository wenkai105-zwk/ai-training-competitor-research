竞品全景
AI培训市场的五类玩家
核心结论
  1. 市场分五类：免费引流IP、C端付费实操课、割韭菜漏斗、高校背书型、B端/政企合作。
  2. "C端付费实操课"里有两个直接竞品（斑码、IMA实操营），定位跟我们高度重合。
  3. "高校背书型"是新发现的类别（交大、北大），说明AI培训正在正规化，但价格门槛高（6千-6.8万）。
  4. 所有C端竞品都没有"养系统"环节——这仍是我们最大差异化空间。
  5. 整体仍是蓝海——"教白领搭AI系统并持续迭代"这个位置，供给严重不足。

04
用户真实反馈
从3,800+条评论中过滤噪音后精选
核心结论
  1. 信任是最稀缺资源——不卖课的真诚内容获得最高好感。割韭菜类竞品（2个案例）让用户防备心极重。
  2. TA画像完全验证——活跃用户是有经验的职场人（设计师、运营、品牌负责人），不是学生或程序员。
  3. 价格敏感度分化明显——有人"只要收费就不用"（小红书123赞），也有人愿意花1.2万报交大训练营。中间价格段（几百到几千）是空白。
  4. 教操作没有前途——用户自己担心"学了会不会白学"。教思维才是长期价值。
  5. 市场已等在那里——用户自发要求学"搭skill"，需求跑在供给前面。

05
需求缺口
10个竞品 + 3,800条评论提炼的5个未被满足的需求
核心结论
  1. 缺口一：教了操作但用不到自己工作上 → 斑码和IMA都没解决场景落地
  2. 缺口二：概念都听过但串不起来 → 秋芝验证串联式科普需求巨大
  3. 缺口三：工具会用但用不好，卡在提问拆解 → 所有竞品都只教工具不教指令设计
  4. 缺口四：国内环境卡死，工具获取是隐形门槛 → 10个竞品无一覆盖
  5. 缺口五：搭好了不会优化迭代 → 两个直接竞品（斑码/IMA）都没有"养系统"环节

课程大纲优化建议
基于10个竞品 + 用户反馈 + 需求缺口
本次优化依据（基于10个竞品的完整分析）
  1. 斑码+IMA实操营是两个直接竞品，都做"工作流"但都没有"养系统" → 我们的核心差异化是迭代机制
  2. 秋芝2046+Rick讲AI占据免费流量，验证概念串联式科普需求 → 免费课和扫盲都借鉴这种形式
  3. 割韭菜类（4级链+3980宝妈课）让用户防备心极重 → 我们必须靠"不卖课的真诚"建立信任
  4. 高校背书型（交大/北大）价格6千-6.8万，说明高净值用户存在但我们走"更实操更亲民"路线
  5. 用户最大缺口是场景落地 → 新增"工作拆解"前置环节
  6. 国内工具环境是隐形门槛，10个竞品无一覆盖 → 新增"工具获取与成本管理"
  7. 用户自发要求学搭skill → 从"展示"升级为"手把手"
